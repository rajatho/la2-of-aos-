# 🚀 Quick Start Guide

## 📋 Option 1: Start the Server (Windows)

### Using Batch File (Easiest)
Simply double-click:
```
START_SERVER.bat
```

### Using PowerShell
```powershell
.\START_SERVER.bat
```

### Using Command Line
```bash
pip install -r requirements.txt
python app.py
```

## 🌐 Option 2: Push to GitHub (Windows)

### Using Batch File
Double-click:
```
PUSH_TO_GITHUB.bat
```

### Using PowerShell
```powershell
.\PUSH_TO_GITHUB.ps1
```

### Using Command Line
Follow the steps in `GITHUB_SETUP.md`
